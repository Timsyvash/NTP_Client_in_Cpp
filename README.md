# 🕒 ESP8266 NTP Time Client (C++ / PlatformIO)

Точний клієнт синхронізації часу за протоколом **NTP (Network Time Protocol)** на базі мікроконтролера **Wemos D1 mini (ESP8266)**. Проєкт демонструє роботу з протоколом UDP (`WiFiUDP`), надсилання запитів до публічних серверів точного часу (наприклад, `time.nist.gov`) та розрахунок поточної дати й часу без використання сторонніх великих бібліотек.

---

## 📌 Особливості проєкту

* **NTP Client з нуля:** пряме формування 48-байтного NTP-пакета та розбір отриманої відповіді через сокети UDP.
* **Автоматична синхронізація:** отримання Unix-часу з урахуванням часового поясу при старті пристрою.
* **Аптайм та компенсація часу:** точний підрахунок поточного часу за допомогою `millis()` після первинної синхронізації (без повторних частих запитів до сервера).
* **Інтерактивна кнопка:** вивід поточного часу та дати у Serial Monitor за натисканням кнопки (на піні `D2`).

---

## 🛠️ Компоненти та розпіновка (Pinout)

### Необхідні деталі:
1. **Wemos D1 mini** (ESP8266) — 1 шт.
2. **Кнопка (Tactile Push Button)** — 1 шт.
3. Якісний USB-кабель.

### Схема підключення:

| Компонент | Пін на кнопці / платі | Пін Wemos D1 mini | GPIO (ESP8266) | Примітка |
| :--- | :--- | :--- | :--- | :--- |
| **Button** | Pin 1 | **D2** | GPIO4 | Кнопка для виводу часу |
| | Pin 2 | **GND** | GND | Спільний мінус |
